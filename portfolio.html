Life OS

Finance and study tracker for two people

Type or say a sentence in Portuguese, like "30 reais do almoço", and it becomes an expense, with undo. It installs as a web app, has a Siri shortcut, and sends reminders before events. Only two accounts can log in, and the access rules live in the database.

Built with JavaScript, Supabase (PostgreSQL, row-level security, Edge Functions), Cloudflare, Node test runner. Ten automated test files cover the parser, the calculations and the API handler.

var reduce = window.matchMedia(
  '(prefers-reduced-motion: reduce)'
).matches;

if (!reduce && window.Lenis) {
  lenis = new Lenis({ lerp: 0.085, smoothWheel: true });
  lenis.on('scroll', ScrollTrigger.update);
  gsap.ticker.add(function (t) { lenis.raf(t * 1000); });
}

Photo-to-ERP robot

Automation in production at Wanessa Lopez Concept, a fashion store

Registering each new piece by hand was slow. Now the team sends a photo to a Telegram bot, an AI identifies the item, and the product appears in the ERP. I tested it with dummy products before it touched real stock.

Built with Make, Telegram Bot API, Gemini API, Olist ERP REST API.

How it works
  1. A team member sends a photo of the piece to the Telegram bot.
  2. Make passes the image to the Gemini API, which describes the piece and fills in the product fields.
  3. Make creates the product in the Olist ERP through its API.
  4. The team checks the new product, with no manual data entry.
